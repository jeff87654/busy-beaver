# 1RB3LB1RZ2RA_2LC3RB1LC2RA_3RB1LB3LC2RC (BB(3,4) champion)

Source: Pavel Kropitz (machine), Shawn Ligocki, *BB(3, 4) > Ack(14)*,
<https://www.sligocki.com/2024/05/22/bb-3-4-a14.html> (2024-05-22).
This file restates that proof; the Coq development in [verify/](verify/) follows it and is
machine-checked.

    0    1    2    3
A   1RB  3LB  1RZ  2RA
B   2LC  3RB  1LC  2RA
C   3RB  1LB  3LC  2RC

Halting transition: **A2 = 1RZ** (A reading a 2 writes 1, moves right, halts).
In busycoq (`verify/BB34_rules.v`) this is the only `None` entry of `tm`; `verify/probe.v`
re-parses the machine string above and checks that all twelve entries agree.

## Notation

- `X` and `Y` in a rule stand for arbitrary left/right context; `A>` = state A, head on the
  first cell of the block to the right (moving right); `<B` = state B, head on the last
  cell of the block to the left.
- Left streams in Coq are written from the head outwards, so `0^inf 3^(2m+1) 2^k A> 1^n R`
  is `Bcfg k n m r` with left stream `[2]^^k *> [3]^^(2m+1) *> const 0`.
- "X → Y" means zero or more steps (Coq's `-->*`).

The one configuration family (Ligocki):

    B(k, n, m) R  =  0^inf  3^(2m+1)  2^k  A>  1^n  R

and the run is

    0^inf A> 0^inf  -(241)->  B(16, 3, 0)  2  0^inf
        ->  B(16, 0, g_15^3(0))  2  0^inf
        -(A2 = 1RZ, 1 step)->  0^inf  3^(2 g_15^3(0)+1)  2^16  1  Z>  0^inf .

The functions (Coq: `g` in `BB34_rules.v`):

    g_0(m)     =  m + 1
    g_(k+1)(m) =  g_k^(2m+2)(0)

## The three rules

1. **Start** (`BB34_start.v`, `start`): the blank tape reaches `B(16,3,0) 2 0^inf` in exactly
   241 steps.  Proven in Coq by stepping (busycoq's `execute`); also cross-checked by
   `tools/sim.py`.  The 241 steps are cut into chunks of 10 (`BB34_start.v` is generated by
   `tools/gen_start.py`), because busycoq's `execute` re-normalises the whole accumulated
   proof term at every step and a single 241-step `execute` is cubic in the number of steps.

2. **Lemma 1** (`BB34_rules.v`, `L1`): `3 2^k <B → 2^k <B 1` (k ≥ 1, 2k+1 steps).
   **Corollary 2** (`Cor2`): `3^m 2^k <B → 2^k <B 1^m` ((2k+1)m steps).

3. **Theorem 3** (`BB34_rules.v`, `B_rule`): for k ≥ 1, n, m ≥ 0:

        B(k, n, m) R  →  B(k, 0, g_(k-1)^n(m)) R

   Proof by double induction (on k, then n), using Lemma 1/Corollary 2 and the
   "turnaround" step sequence

        0^inf 2^(k+1) <B 1^(2m+1) 3 1^n R  →  0^inf 3 2^k A> 1^(2m+2) 3 1^n R .

   The Coq proof decomposes these into elementary sweeps (`C_sweep_left`, `C_right_3s`,
   `A_3s`, `B_1s`, `BA_sweep`, `turnaround`), each proven by a simple induction.

4. **Halting step** (`BB34_run.v`): `B(k, 0, m) 2` — A reads the 2, i.e. `c_final =
   Bcfg 16 0 g15 (2 >> const 0)` with `g15 = g_15^3(0)` — the machine halts there;
   the halting write turns the 2 into a 1, so the final tape is
   `0^inf 3^(2 g15+1) 2^16 1 Z> 0^inf` with `sigma = 2 g15 + 18` nonzero cells.

## The score

Closed form (BB34_score.v, `g_closed`), by induction on k, using
`Nat.iter` lemmas and the coincidence `2 ↑^k 2 = 4`:

    2 * g_(k+1)(m) + 4  =  2 ↑^k (2m+4)

Corollary (`g_iter_closed`): `2 * g_k^n(0) + 4 = 2 ↑^k (n+2)`; with k = 15, n = 3:

    sigma = 2 * g_15^3(0) + 18 = (2 ↑^15 5) + 14.

(`knuth n a b` in Coq is a ↑^n b with a ↑^0 b = a·b, as in Ligocki's post.)

The last step, `sigma_eq`, is where the two closed forms meet.  `g15` is sealed behind a
`sig` (`g15_spec`/`g15_eq`), the rule `B_rule` is instantiated through the abstracted
version `B_rule_gen` so that no conversion between `g15` and the raw
`Nat.iter 3 (g 15) 0` is ever required, and the arithmetic is done by the generic lemma
`score_generic : 2x+4 = K -> 2x+18 = K+14`.  See `verify/coq_quirks.md` for why this is
necessary.
