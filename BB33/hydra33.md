## How it works

BB33 plays the same hydra game as BB29 (see [`../BB29/hydra29.md`](../BB29/hydra29.md), section 1), with the
same pair-level program up to a renaming of states. The tape pairs are shifted by one cell relative to BB29. The
only real difference is the left-scanning depth counter: states R T V X ` S U track bracket depths 0–6, with escape state
W, so the machine handles hydras of height up to **7** (BB29: 3).

From the blank tape, 288 steps reach C(1): counter m = 1 and the hydra root → Y₁ → … → Y₆, where Y₄ = (leaf, Y₅) and Y₆ has 3 leaves, whose ordinal (the
ordinary sum o(node) = ω^{o(c₁)} + … + ω^{o(c_k)} in tape order) is **ω^ω^ω^ω^ω^ω^3** (`x0_eq`).

## Proof

Halting and the bound come from one well-founded argument: the game is an instance of a generic Hardy-hierarchy
lemma (`Hardy.hardy_game`, by well-founded induction on the ordinals below ε₀). Each round takes α = o(hydra) to
α − 1 (the cut head hangs from the root) or into [α[m+3], α) (otherwise), with m → m + 1, and the empty hydra halts
with m + 1 ones. Unlike BB29's, the hydras here are not kept sorted (some nodes carry an extra leading leaf);
`HydraOrd.chop_ord` proves the interval property for every hydra, sorted or not, using the Bachmann property
x[n] < y < x ⇒ x[n] ≤ y[1] (`bachmann`). The result is N + 2 ≥ H_{ω^ω^ω^ω^ω^ω^3}(4), and H_{ω^β} = f_β with β = ω^ω^ω^ω^ω^3 = (ω↑↑6)[3] gives
`hardy_score`. Then f_x(3) + 3 ≤ f_x(4) for limit x (`FGH_lim_step`) gives the posted claim. A weaker corollary,
f_{ω^ω^ω^ω}(3) < N, is `sigma_lower_bound`.
