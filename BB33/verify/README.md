# Coq proofs for BB33

`multifile/` is a Coq development on top of [busycoq](https://github.com/meithecatte/busycoq) (commit `bd2e36f`,
Coq 8.20.1). For the machine

    1LH1L^_---0LC_1LR0LB_1RF1LE_0LD1LD_0R_1RG_1RN0RK_0RI1RJ_1L^1RH_0RH1RH_0RL1RM_1L`1RK_0RK1RK_0RO1RO_0L`1RN_1R_1La_0RZ0RZ_0LX1LS_0R_1LT_0L`1LU_0LR1LV_0LS1LW_0LT1LX_0R]1LY_0LV1L`_0R[1R\_0RN1RZ_0LC1RZ_0La1L^_0L]1L]_0RQ0RH_1LA1LR_0LP1LD

(B0 undefined = the halt) it proves:

- `BB33_halt.halt : halts tm c0`: the machine halts from the blank tape;
- `BB33_bound.hardy_score`: the halting tape holds N ones with `FGH (powtower 5 (ofin 3)) 4 <= N + 2` (`powtower 5 (ofin 3)` = ω^ω^ω^ω^ω^3);
- `BB33_bound.sigma_lower_bound_w6`: `FGH (tower 6) 3 < N` (`tower 6` = ω↑↑6), the posted claim;
- `BB33_bound.sigma_lower_bound`: `FGH (tower 4) 3 < N` (weaker).

The ordinals below ε₀ and the fast-growing hierarchy are defined in `Ord.v`: hereditary Cantor normal form
(`ord := oz | ow a b`, ω^a + b), the standard fundamental sequences ((β + ω^(γ+1))[n] = β + ω^γ·n,
(β + ω^λ)[n] = β + ω^(λ[n]), ω^ω[n] = ω^n), and f as an inductive relation `fgh` (f_0(n) = n+1,
f_(α+1)(n) = f_α^n(n), f_λ(n) = f_(λ[n])(n)), proved deterministic and total below ε₀, so `FGH` is a function;
`tower k` = ω↑↑k. `ones c N` says the tape of c is a finite word padded with 0s holding N ones. `probe.v` prints
all of these definitions.

## Files

| file | content |
|---|---|
| `BB332.v`, `Individual332.v` | busycoq instantiated for 33 states. State character c is the constructor q + the spreadsheet column of ord(c) − 65: A..Z → qA..qZ, then `[`, `\`, `]`, `^`, `_`, `` ` ``, `a` → qAA..qAG. This avoids clashes with L, R, S, O, I, Q, Z. |
| `BB33_tm.v` | the transition table, with the machine string in its header |
| `BB33_rules.v` | pair alphabet, state roles, atomic pair rules |
| `BB33_scan.v` | scan lemmas, depth scans over trees, the copy lemma |
| `BB33_round.v` | round lemmas |
| `BB33_game.v` | the hydra game as an instance of `hardy_game` |
| `BB33_halt.v` | the 288-step opening, the initial hydra, `halt` |
| `BB33_bound.v` | the FGH statements |
| `Hardy.v` | Hardy hierarchy, `hardy_game` |
| `HydraOrd.v` | hydras, their ordinals, `chop_ord`, the Bachmann property |
| `Ord.v`, `Hardy.v`, `HydraOrd.v` | shared library, byte-identical in BB29/, BB31/ and BB33/ (`Ord.v` in all three; `Hardy.v` and `HydraOrd.v` in BB31/BB33) |
| `probe.v` | the independent probe (below) |
| `compile_clean.sh`, `_CoqProject` | build script, project file |
| `compile_clean.log`, `probe.log`, `sha256.txt` | logs of a from-scratch build, hashes of the source files |

The machine files (`BB33_*.v`) are generated by [`../../BB31/verify/generator/gen.py`](../../BB31/verify/generator/gen.py) from templates shared by BB31 and BB33; running it reproduces them byte for byte.

## Check it

    cd multifile
    BUSYCOQ=/path/to/busycoq/verify ./compile_clean.sh

`probe.v` checks the compiled transition table against the machine string entry by entry (lines generated from the
string, not from the Coq file; rows are fixed-width), prints the definitions the statements use, and runs
`Print Assumptions` on the four theorems above: all four are closed under the global context. CI job `bb13-bb14`
runs the same script.
