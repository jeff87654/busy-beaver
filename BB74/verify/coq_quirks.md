# Coq quirks in the BB74 development

## 1. Cut the blank-tape run into chunks

`BB74_start.v` proves 730 steps with 10-step chunks, generated by
`../tools/gen_start_chunks.py`.  A single `execute` over the whole run
re-normalises the accumulated proof term at every step and is cubic.

The final equality needs a little stream normalisation:

    unfold cfg_730, Bcfg. simpl.
    rewrite <- (const_unfold sym S0).
    reflexivity.

## 2. Keep the parameter chain opaque

`m1`…`m24`, `next`, `gamma`, `round` and `mfin` are opaque.  Writing
`change (... m4 ...)` while `m4 := gamma m3` made Coq try to normalise an
Ackermann-level numeral and hang.  Use the `_eq` lemmas and `rewrite`, not
conversion.

`BB74_score.v` temporarily makes `next` transparent only to expose its defining
`Nat.iter (2*m+2) round 6`; `round` stays opaque.

## 3. F2 is not a halt

BB74 reuses BB83's `B_rule` and `rule2`, but the tail rules are:

    B(1,0,m) 0 0 r -> B(1,0,round m) 0 r
    B(1,0,m) 0 1 r -> B(2,1,0) 0^(2m+3) r
    B(1,0,m) 0 2 r -> B(2,1,0) 0^3 1^(2m+3) r
    B(1,0,m) 0 3 r -> F> 3 r  (F3 = 1RZ halts)

The BB83 `halt_from_B` was therefore renamed to `reach_F_on_2`; the new
`halt_from_B` is for marker 3.  `rule3c` passes through a G/A/F loop that
moves the freshly written `1` block back into the left stream before the
fresh zero block is consumed.

## 4. Bcfg still prepends the `1^n` block

`Bcfg k n m r` has right stream `[1]^^n *> r`.  After `initial_desc`, the
visible right stream is `0 >> r`; passing an extra `0` to `tail_zeros` is a
common source of off-by-one errors.

## 5. Arithmetic and comparison tactics

* `lia` knows `<=`, `<` and `=` but not `>=`, and cannot compare applications
  of opaque functions except as atoms.  Prove equalities of arguments first.
* Natural numerals in `Bcfg`/`round` arguments sometimes need `%nat`, because
  `0`, `1`, `2`, `3` are notation for symbols in `sym_scope`.
* In the `f_omega2`/`gamma` induction, use `exact (IH j ltac:(lia))` rather
  than `apply IH; lia`: the latter hangs in Coq's unification at an
  opaque `Nat.iter` term.
* Prove `gamma_eq_achain : gamma m = achain (2*m+3)` once and rewrite with it;
  do not unfold `gamma` inside the induction.
* The clean build writes `compile_clean.log` and `probe.log`; the latter must
  contain the main `Closed under the global context` lines and no `Axioms:`
  line.
